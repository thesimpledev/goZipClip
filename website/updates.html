Updates

What's new in ZipClip.

Windows 0.4.0 alpha
Linux 0.4.0 alpha

August 22, 2026 (0.6.0)

  • You can see what is happening, and stop it. The Status tab now shows the download as it runs (percentage, speed, time left) and each ffmpeg step with its position in the video, instead of a single "downloading" line until the end. A red Cancel button stops the run in progress; Pause still only holds the scheduled runs. (Windows 0.6.0, Linux 0.6.0)
  • The channel is checked and cataloged when you set it. Entering the channel name checks that it exists on Twitch and asks you to confirm it. Confirming catalogs every VOD already on the channel, so your history is never downloaded, and leaves the newest three to be processed on the first run. After that, every run downloads whatever is new. The "Mark existing VODs as downloaded" button is gone; it happens by itself now.
  • Processed videos. "Show files to upload" is replaced by a "Processed videos" button on the Status tab that lists every VOD ZipClip has handled, newest first, with a Forget button to have one downloaded and processed again on the next run.
  • Missing settings are asked for, not reported as errors. When a run needs something that is not set, such as the intro file, ZipClip walks you through it one item at a time, with the choice to fill it in or turn that step off, and then starts the run.
  • Settings save on their own. Checkboxes save as soon as they change and text fields when you press Enter or move on; a green "Saved" or red "Not saved" line at the bottom of the tab shows the state. The intro checkbox now reads "Add an intro video to the start of each VOD".
  • Fixed: on Windows, Run now (and the yt-dlp update at launch) opened an empty black console window. The tools now run without one.

August 15, 2026 (0.5.0)

  • The cut and the intro are now optional. Two new checkboxes in Settings, "Cut the starting-soon screen" and "Splice the intro", turn each step off on its own. Both stay on by default. With the intro off, no intro file is needed; with both off, ZipClip becomes a pure VOD downloader and delivers each new VOD to the output folder exactly as downloaded. (Windows 0.5.0, Linux 0.5.0)
  • A quiet opening no longer stops the run. When no scene change is found in the scan window, ZipClip now keeps the full VOD from the very beginning instead of stopping with an error. In dev mode the Approve tab still lets you set the cut time by hand.

August 13, 2026 (0.4.0)

  • Nothing to install on Windows. The Windows download now ships ffmpeg and yt-dlp in the same folder as zipclip.exe: a small ffmpeg built just for ZipClip, and the official yt-dlp, which ZipClip updates on every launch so it keeps up with Twitch on its own. Unzip and run; the setup guide no longer has an install step. Setting your own paths in Settings still works and always wins. (Windows 0.4.0)
  • Run latest VOD works while you are live. The button now grabs your newest finished VOD even when the channel is currently streaming, instead of stopping with an error. ZipClip still never downloads a stream that is in progress. (Windows 0.4.0, Linux 0.4.0)
  • Fixed: starting a new stream at the wrong moment could mark that stream's VOD as already handled, so the nightly run would skip it forever. The record now always matches the file that was actually downloaded.

August 12, 2026 (0.3.0)

  • YouTube uploads. ZipClip can now upload each finished video to your channel by itself, as a private video you publish from YouTube Studio. One checkbox switches between automatic uploads and manual mode, and a "Show files to upload" button lists what is waiting in the output folder. Setup takes one Google console visit; the setup guide walks through it. (Windows 0.3.0, Linux 0.3.0)

August 12, 2026 (0.2.0)

  • ZipClip 0.2.0. Out now for Windows and Linux. (Windows 0.2.0, Linux 0.2.0)
  • No more Twitch application. Setup no longer asks you to register a Twitch application or paste API credentials. ZipClip simply runs at the time you pick.
  • Full runs by default. Every run now goes end to end on its own: download, detect, cut, splice, verify, clean up. The old approve-each-cut flow is still there as an optional dev mode for checking the detection step by step.
  • Run latest VOD. A new button processes the newest VOD on the channel on demand, even if it was already marked as handled (with a warning first).
  • Reset buttons. Settings and the download archive can each be reset from the Settings tab.
  • 12-hour clock. The daily run time is now entered as, for example, 8:00 PM.
  • Settings moved. The settings, log, and download archive now live in your user configuration folder (Windows: %AppData%\zipclip, Linux: ~/.config/zipclip), so ZipClip can be unpacked anywhere.

August 7, 2026

  • Windows alpha. ZipClip 0.1.0 is now available for Windows as a portable zip: unzip anywhere and run zipclip.exe, no installation needed. (Windows 0.1.0)
  • First alpha release. ZipClip 0.1.0 is out for Linux. It watches your Twitch channel once a day, downloads new VODs, finds where the starting-soon screen ends, splices your intro onto the front without re-encoding, and drops the finished video in the folder your upload tool watches. (Linux 0.1.0)
